How a sample is runEach docs page gets a new Linux machine on Boat. The SDKs are installed with the commands the docs give, then every sample is saved to a file and run exactly as published, with nobody at the keyboard.
What counts as brokenA non-zero exit code, an HTTP status of 400 or above from a curl command, or no result within 150 seconds. Rate limits are retried and never counted.
What is never runSamples that delete or cancel, samples with a value the reader must fill in, fragments that are not whole programs, and example output. Each one says why.
