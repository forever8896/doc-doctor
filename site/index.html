Do the examples in your docs still work?

Doc Doctor runs every code sample in your docs on a fresh machine and records what happens.

git clone https://github.com/forever8896/doc-doctor && node doc-doctor/bin/doc-doctor.mjs serve

Open source. It runs on your own Boat account, and your API key stays with you.

Each report is the full result: one square per code sample, with a terminal recording you can replay.

How it works

No test files to write. The docs are the test suite.

  1. Reads your docsEvery code block on every page. It works out your API host, key variable and SDK install commands from the samples.
  2. Decides what a reader could runWhole programs with nothing to fill in. Fragments, example output and anything that deletes are skipped, each with a reason.
  3. Runs each sample on a new machineOne Boat sandbox per page. Your install commands first, then the sample exactly as written.
  4. Keeps watchingWhen a page changes, only the new or edited samples run again.
  5. Optional: keeps your key in a vaultWith 1Claw, the machines call your API through the vault and never hold the key.
